# 万象阁

一个自己写、自己用的桌面工具箱，目前主要在 Windows 上使用和测试。

下载视频、转换音视频和图片、处理 PDF、手机和电脑互传文件，再加几个日常小工具，都放在一个软件里，不用每次去找网站或者装一堆小软件。

---

## 能做什么

### 下载

- **视频下载**：粘贴链接，选清晰度，点下载。B 站、YouTube、抖音、小红书、X（推特）等网站可以解析，底层是 yt-dlp。网站改版后可能暂时失效，升级 yt-dlp 一般能解决。
- **Bing 每日壁纸**：一次下载多个地区、多天的壁纸，保存为高清图片。

### 媒体

- **图片格式转换**：PNG、JPG、WebP、BMP 互相转换，可以选一个文件夹整批转。
- **视频处理**：转成 MP4、转成 GIF、只提取声音、只保留画面（去掉声音）。可以一次选多个文件。转 MP4 时能在设置里选"老旧设备兼容"模式，给老电视、老数码设备用。
- **音画合成**：给视频换声音或加背景音乐。音频那一栏也可以直接选另一个视频，用它的声音。另外可以把多个视频按顺序拼成一个。
- **长度截取**：从视频或音频里截一段，填起点和时长（或结束时间）。默认的快速模式不重新编码，起点可能比你填的早几秒；勾选"精确切割"会重新编码，慢一些，但起止点是准的。

### 文档（PDF）

- 合并多个 PDF
- 拆分：挑几页另存成新文件
- 调整页面顺序，比如把第 8 页挪到第 2 页
- PDF 每一页转成图片；多张图片合成一个 PDF
- 提取文字，保存成 txt。扫描件、图片版 PDF 没有文字层，提取不出来。

### 工具

- BMI 计算
- 人民币大写转换，写合同、报销单时用
- 简体、繁体互转
- 随机强密码，4 到 32 位，可选是否包含数字、大小写字母、特殊字符
- 常用符号表，点一下就复制
- 文件夹目录树：把一个文件夹里的文件结构导出成 txt，可以只看前几层

### 传送

电脑上点"启动传送服务"，屏幕上出现二维码，手机扫一下，在手机浏览器里就能和电脑互传文本和文件，手机上不用装任何东西。

- 电脑发给手机、手机发给电脑，文本和文件都行，可以一次选多个文件
- 数据只在局域网里走，不经过任何服务器
- 每次启动服务会生成新的访问口令，写在链接里，没有链接的人进不来
- 另一台电脑（在同一个局域网）理论上也能用：在浏览器里打开同一个链接就行，对方电脑不用装万象阁
- 实测一个 4.9 GB 的文件，电脑到手机约 1 分钟，手机到电脑约 1 分 45 秒，不同网络环境速度会不一样

## 用打包好的 exe

双击运行，不用装 Python，也不用另外装 FFmpeg，已经带在里面了。

### Cookie 放在哪、怎么导入

大部分公开视频不需要 Cookie。没有 Cookie 时程序会先尝试匿名解析，解析不了（会员视频、要登录才能看、被网站拦截）才需要导入。

导入方法：设置 → Cookie 导入 → 选网站 → 选一个 `cookies.txt` 文件。目前支持 YouTube、B 站、抖音、小红书、X。文件要用浏览器扩展导出，格式是 Netscape 格式。导入后程序会自动改成需要的文件名，不用自己改。

导入后的文件存在这里：

1. 打开任意一个文件夹窗口
2. 在顶部地址栏输入 `%APPDATA%\万象阁`，回车
3. 里面的 `cookies` 文件夹就是各网站的 Cookie，`settings.json` 是软件的设置（主题、MP4 模式等）

想删掉某个网站的 Cookie，可以在设置页点移除，也可以直接去这个文件夹里删文件。

几点说明：

- 打包好的 exe 里不带任何 Cookie，发给别人用的话，对方得自己导入自己的
- Cookie 相当于登录凭证，别把自己的 `cookies.txt` 发给别人
- 这个目录在 exe 外面，所以换新版 exe 之后，之前导入的 Cookie 和设置还在
- 从源码运行时不用这个路径，Cookie 和设置放在项目里的 `config/` 文件夹

### 第一次用传送功能

Windows 防火墙可能会弹窗问是否允许联网，选"专用网络"允许。不允许的话手机连不上。传送服务用的是 8000 端口。

用完建议点"关闭传送服务"。同一个局域网里拿到链接的人都能传文件。

## 三个入口

同一套功能有三种用法：

- **命令行**：不开窗口，直接在终端里用
- **Flet 界面**
- **PySide6 界面**：支持把文件直接拖进窗口，Flet 版目前做不到这一点

两个界面的功能一致，日常用哪个都行。

---

## 从源码运行

需要 Python 3.14 和 [uv](https://github.com/astral-sh/uv)。

```bash
uv sync
```

FFmpeg 和 FFprobe 放到 `assets/ffmpeg/bin/` 下。没放的话程序会去系统 PATH 里找。

启动：

```bash
# 命令行
uv run python main.py

# Flet 界面
uv run python -m ui.flet_ui.main

# PySide6 界面
uv run python -m ui.pyside6.main
```

要在项目根目录（`pyproject.toml` 所在的那层）运行。界面入口用的是 `-m`，不能写成 `python ui/pyside6/main.py`，那样 Python 找不到 `tools` 目录，会报 `ModuleNotFoundError`。

视频下载里"Aria2 加速"这个选项需要电脑上已经装了 aria2，程序不自带。

---

## 打包

用 PyInstaller，Flet 和 PySide6 各有一个 spec 文件，互不影响：

```bash
uv run pyinstaller 万象阁-flet.spec --clean --noconfirm
uv run pyinstaller 万象阁-pyside6.spec --clean --noconfirm
```

打包前确认：

- `assets/` 里有 `icon.ico`、`icon.png` 和 `ffmpeg/bin/` 下的两个 exe
- 不要把 `config/cookies/` 打进去，否则你自己的 Cookie 会跟着软件发出去

## 项目结构

界面只负责按钮和显示，真正干活的代码都在 `tools/` 里，命令行、Flet、PySide6 共用同一套。

```
toolbox/
├── main.py          命令行入口
├── cli/             命令行界面
├── tools/           功能代码（下载、媒体、PDF、传送、Cookie、路径等）
├── ui/
│   ├── flet_ui/     Flet 界面
│   └── pyside6/     PySide6 界面
├── assets/          图标、FFmpeg
├── config/          开发时的设置和 Cookie（打包版不用这里）
├── tests/           测试
├── 万象阁-flet.spec
├── 万象阁-pyside6.spec
└── pyproject.toml
```

Flet 的目录叫 `flet_ui` 而不是 `flet`，是因为和第三方包 `flet` 同名，PyInstaller 打包时会冲突。

用到的主要库：yt-dlp、FastAPI、Uvicorn、PyMuPDF、Pillow、OpenCC、aiofiles、qrcode。界面是 Flet 0.86.5 和 PySide6 6.11 以上。
