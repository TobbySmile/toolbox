# 万象阁（Toolbox）

一个自己写、自己用的 Windows 桌面工具箱。

视频下载、音视频处理、图片转换、PDF 工具、手机与电脑互传文件，以及一些日常小工具，都集中在一个软件里，尽量减少在不同网站和小软件之间来回切换的麻烦。

## 功能介绍

### 下载

- **视频下载**：粘贴视频链接、选择清晰度并下载。基于 `yt-dlp`，支持解析 B 站、YouTube、抖音、小红书、X（原 Twitter）等网站。网站改版、访问限制或解析规则变化都可能导致暂时无法下载；更新 `yt-dlp` 有时可以解决问题，但不保证始终有效。
- **Bing 每日壁纸**：按地区和日期批量下载高清壁纸。

### 媒体

- **图片格式转换**：支持 PNG、JPG、WebP、BMP 格式互转，也可以批量转换文件夹中的图片。
- **视频处理**：转换为 MP4 或 GIF、提取音频、移除音轨保留画面；支持批量处理。MP4 转换可选择“老旧设备兼容”模式。
- **音画合成**：为视频更换音轨或添加背景音乐，音频输入也可以选择另一个视频并提取其声音；还可以按指定顺序拼接多个视频。
- **音视频截取**：按起始时间和时长（或结束时间）截取片段。快速模式不重新编码，处理速度快，但起点可能受关键帧影响；开启“精确切割”后会重新编码，速度较慢，但通常能更准确地控制起止位置。

### 文档（PDF）

- 合并多个 PDF 文件。
- 选择指定页面，拆分并另存为新的 PDF。
- 调整 PDF 页面顺序，例如将第 8 页移动到第 2 页。
- 将 PDF 页面转换为图片，或将多张图片合成为一个 PDF。
- 提取 PDF 文字并保存为 TXT。扫描件或纯图片 PDF 如果没有可提取的文字层，目前无法直接提取文字。

### 日常工具

- BMI 计算。
- 人民币金额大写转换，方便填写合同、报销单等。
- 简体中文与繁体中文互转。
- 生成 4–32 位随机密码，可设置是否包含数字、大写字母、小写字母和特殊字符。
- 常用符号表，点击即可复制。
- 文件夹目录树：将文件夹结构导出为 TXT，并可限制显示的目录深度。

### 电脑与手机互传文件

电脑端启动传送服务后会显示二维码。手机扫码即可在浏览器中打开传送页面，不需要在手机上安装万象阁。

- 电脑与手机之间可以互传文本和文件，也支持一次选择多个文件。
- 电脑端运行本地服务，设备之间通过局域网地址直接通信；万象阁不提供自建的云端中转服务。
- 每次启动服务都会生成新的访问口令，并放入访问链接中。
- 同一局域网中的其他电脑也可以通过浏览器打开该链接，不必安装万象阁。
- 测试环境中，传输一个约 4.9 GB 的文件，电脑到手机约 1 分钟，手机到电脑约 1 分 45 秒。实际速度取决于设备、Wi-Fi、网卡和网络环境。

> **传送功能的安全提示：** 请只在可信的局域网中使用，不要把访问链接分享给不信任的人。局域网 HTTP 传输不等同于端到端加密，不建议用它传输高度敏感的数据。首次启动时，Windows 防火墙可能询问是否允许访问网络；如需让局域网设备连接，请根据实际网络情况允许专用网络访问。默认服务端口为 `8000`，用完后建议关闭传送服务。

## 使用打包版

打包版面向 Windows 用户，通常可以直接运行，不需要另外安装 Python。发布包是否包含 FFmpeg，以对应版本的发布说明和实际打包内容为准。

### Cookie 的导入与存放

大部分公开视频不需要 Cookie。程序会优先尝试匿名解析；对于需要登录、会员权限或受到网站限制的内容，才可能需要导入 Cookie。

导入方法：打开“设置” → “Cookie 导入” → 选择网站 → 选择对应的 `cookies.txt` 文件。目前支持 YouTube、B 站、抖音、小红书和 X。Cookie 文件应使用浏览器扩展导出为 Netscape 格式。导入后，程序会自动使用所需的文件名，不需要手动重命名。

可以在浏览器扩展商店安装 **Get cookies.txt LOCALLY**，将已登录网站的 Cookie 导出为 Netscape 格式的 `cookies.txt`：[Chrome 网上应用店](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)；[Firefox 附加组件](https://addons.mozilla.org/firefox/addon/get-cookies-txt-locally/)。请确认扩展来源后再安装，并只导出自己有权使用的账户 Cookie。导出的 Cookie 等同于登录凭证，请勿分享给他人或上传到代码仓库。

打包版的 Cookie 和设置保存在用户数据目录中：

1. 打开任意一个文件夹窗口。
2. 在地址栏输入 `%APPDATA%\万象阁` 并按回车。
3. `cookies` 文件夹存放各网站的 Cookie；`settings.json` 保存主题、MP4 转换模式等设置。

可以在软件设置页移除某个网站的 Cookie，也可以直接删除 `cookies` 文件夹中的对应文件。该目录位于 EXE 外部，因此升级应用版本时，原有 Cookie 和设置通常会保留。

- 打包版不会附带任何个人 Cookie；其他用户需要自行导入自己的 Cookie。
- Cookie 相当于登录凭证，请勿将自己的 `cookies.txt` 或 Cookie 文件发送给他人，也不要提交到 GitHub。
- 从源码运行时，配置和 Cookie 使用项目的 `config/` 目录；打包版使用上述用户数据目录。

## 三种使用入口

万象阁提供三种使用方式：

- **命令行**：直接在终端中运行，不需要打开桌面窗口。
- **Flet 界面**：使用 Flet 构建的桌面 UI。
- **PySide6 界面**：使用 PySide6 构建的桌面 UI，支持将文件直接拖入窗口；Flet 版目前不支持该操作。

两个桌面界面共用同一套底层功能，具体交互细节可能有所不同。

## 从源码运行

### 环境要求

- Windows（主要开发和测试平台）。
- Python 3.14，建议使用项目 `.python-version` 指定的版本。
- [uv](https://github.com/astral-sh/uv)：用于管理 Python 环境和项目依赖。
- FFmpeg 与 FFprobe：媒体处理功能需要这两个可执行文件。

### 安装依赖

在项目根目录（`pyproject.toml` 所在目录）打开终端，执行：

```powershell
uv sync
```

**FFmpeg 说明：** 出于 GitHub 普通仓库的文件大小限制，源码仓库不直接包含 `assets/ffmpeg/bin/` 下的 `ffmpeg.exe` 和 `ffprobe.exe`。如需使用媒体处理功能，可以将这两个文件放入 `assets/ffmpeg/bin/`，或者安装 FFmpeg 并确保 `ffmpeg`、`ffprobe` 可以通过系统 `PATH` 找到。获取和使用 FFmpeg 时，请遵守对应构建版本的许可要求。

### 启动方式

请从项目根目录执行以下命令：

```powershell
# 命令行
uv run python main.py

# Flet 界面
uv run python -m ui.flet_ui.main

# PySide6 界面
uv run python -m ui.pyside6.main
```

桌面界面使用 `-m` 方式启动，以确保 Python 能正确识别项目模块。不要直接使用 `python ui/pyside6/main.py` 运行，否则可能因为模块搜索路径不同而出现 `ModuleNotFoundError`。

视频下载中的“Aria2 加速”选项需要另外安装并配置 `aria2`；项目不会自动提供该外部程序。

## 打包应用

项目使用 PyInstaller，通过不同的 spec 文件分别打包 Flet 和 PySide6 版本：

```powershell
uv run pyinstaller 万象阁-flet.spec --clean --noconfirm
uv run pyinstaller 万象阁-pyside6.spec --clean --noconfirm
```

打包前请确认：

- `assets/` 中存在 `icon.ico` 和 `icon.png`。
- 如需将 FFmpeg 随应用一起打包，请先将 `ffmpeg.exe` 与 `ffprobe.exe` 放在 `assets/ffmpeg/bin/`，并确认 spec 文件已正确配置相关资源。
- 不要将个人 Cookie 或含有个人数据的 `config/cookies/` 打包进应用。

## 项目结构

界面层主要负责按钮、输入和结果展示，实际功能由 `tools/` 中的模块实现；命令行、Flet 和 PySide6 共用这套底层代码。

```text
toolbox/
├── main.py                  # 命令行入口
├── cli/                     # 命令行功能
├── tools/                   # 下载、媒体、PDF、网络、传送等功能
│   └── utils/               # 文件、路径、FFmpeg 等通用工具
├── ui/
│   ├── flet_ui/             # Flet 界面
│   └── pyside6/             # PySide6 界面
├── assets/                  # 图标及本地资源；FFmpeg 二进制需单独准备
├── config/                  # 源码运行时的配置和 Cookie
├── tests/                   # 自动化测试
├── 万象阁-flet.spec          # Flet 打包配置
├── 万象阁-pyside6.spec      # PySide6 打包配置
├── pyproject.toml           # 项目与依赖配置
└── uv.lock                  # 依赖锁定文件
```

Flet 界面目录命名为 `flet_ui`，而不是 `flet`，是为了避免与第三方 `flet` 包同名，并减少打包时的模块冲突风险。

主要依赖包括 `yt-dlp`、FastAPI、Uvicorn、PyMuPDF、Pillow、OpenCC、`aiofiles` 和二维码相关库。界面基于 Flet 0.86.5 与 PySide6 6.11 及以上版本开发，具体依赖以 `pyproject.toml` 和 `uv.lock` 为准。

## 测试

在项目根目录执行：

```powershell
uv run pytest
```

目前的测试覆盖 BMI、人民币大写转换、下载、多媒体和文件选择等功能。测试覆盖范围不代表所有网站、媒体格式或硬件环境都已验证。

## 已知问题

- 安卓 Firefox 在选择较大文件上传时曾出现闪退，原因尚未确认；手机自带浏览器上传正常。
- 扫描版或纯图片 PDF 暂不支持 OCR，因此通常无法直接提取其中的文字。
- 视频网站可能调整页面结构、访问策略或接口，导致下载功能暂时失效。
